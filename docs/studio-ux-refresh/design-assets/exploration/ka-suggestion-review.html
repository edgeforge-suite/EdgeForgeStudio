Knowledge Assist — Suggestion Review
Every suggestion is a reviewable patch with an evidence basis. Decisions stage (accept · edit · reject) and save as one batch — the same 3-way lifecycle Studio persists today.
Knowledge Assist is opt-in and OFF by default. This surface exists only when KA is enabled for the session. With KA off there is no KS UI, no drawer state, no live KS calls. KA build remains gated on the production-readiness / data-handling decision — this design is exploratory and does not unblock it.
