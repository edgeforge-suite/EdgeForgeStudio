The full page is the narrow contract. Standard page semantics and native browser-back avoid a focus trap. PR-24a records keyboard-only + screen-reader navigation walkthroughs and verifies visible focus, route/back restoration, the dirty guard, and the structural save success/failure announcement contract (live-region attributes and writer→region binding, test-enforced). Observing announcements spoken is A11y-01, a mandatory pre-release gate — see §7.2 of implementation-design.md.
G1 rules — identical at every breakpoint: one item per save request (single-item upsert) · Cancel restores only the selected item · dirty browser-back prompts · board rows re-render from the save response’s ReadinessItem (never an optimistic client summary) · validation errors deep-link to the exact tab + field. Breakpoints are presentation-only — no behavioural fork between split and full-page focus. Orientation only — a faithful visualization of Phases 2a–2b + the supported narrow fallback, not a substitute for implementation-design.md, which stays the source of truth.
